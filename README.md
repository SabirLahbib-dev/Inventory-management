# Gestion d'Inventaire

Application web simple pour gérer un stock de produits.

## Description
Ce projet permet d'ajouter des produits, de modifier leurs quantités, de les supprimer et de suivre le nombre total d'articles ainsi que la valeur du stock. Les données sont stockées localement dans le navigateur grâce à `localStorage`.

## Fonctionnalités
- Ajouter un produit avec nom, description, prix, quantité et image
- Augmenter ou diminuer la quantité d'un produit
- Supprimer un produit
- Afficher automatiquement le total des produits et la valeur du stock
- Interface simple et responsive

## Technologies utilisées
- HTML
- CSS
- JavaScript

## Lancement
Ouvrez simplement le fichier `Magasin.html` dans votre navigateur.

## Structure du projet
- `Magasin.html` : page principale
- `Magasin.js` : logique de rendu et gestion des produits
- `Data/products.js` : liste initiale des produits et fonctions de gestion
- `scripts/` : scripts auxiliaires
- `Styles/` : feuilles de style
- `images/` : images des produits
